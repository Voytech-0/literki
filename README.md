# Literki

Polish take on [Letroso](https://letroso.com): find the secret word using letter order, joins and start/end markers. Live at https://voytech-0.github.io/literki

```sh
npm i
npm run dev    # local
npm test       # scoring tests
```

Word lists in `public/` are generated by `scripts/build_words.py` from SJP.PL (CC BY 4.0) — see the script header for sources. Domain docs: `CONTEXT.md`, decisions: `docs/adr/`.
