# 4. Word lists from SJP.pl

Valid guesses: SJP.pl game list (https://sjp.pl/sl/growy/, GPL 2 or CC BY 4.0 — we take CC BY 4.0, attribute in UI). Includes inflected forms.

Secret list: SJP base forms (https://sjp.pl/sl/odmiany/), 4–10 letters, ranked by OpenSubtitles FrequencyWords (CC BY-SA 4.0, used only at build time to rank), top ~3–5k, then a manual skim to drop vulgar or awkward words. Unfiltered SJP lemmas would be too obscure for a daily game.

Generated by `scripts/build_words.py`; outputs committed. Lemma must itself appear ≥100× in the frequency list, and lines whose head word is an inflection of a stronger lemma (kina→kino) are dropped. Names (daniel, gordon) still leak through — manual skim pending.
